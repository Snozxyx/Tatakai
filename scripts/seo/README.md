The standalone `server.mjs` and Vite preview plugin render entity-specific share metadata without JavaScript. Anime, manga, novels, public profiles, posts, playlists and tier lists use TatakaiAPI's public share endpoints. The default banner is `/assets/logo/crimson-sakura-banner.png`.

`SITE_ORIGIN` and `SEO_INDEX_PATH` configure one website. When `SEO_APP_INDEX_PATH` is also set, an explicit Host allowlist selects separate tatakai.app and tatakai.me releases and canonical URLs. `SHARE_API_ORIGIN` points to the API; the renderer needs no credentials.

Sitemap paths proxy the API's paginated live catalog and public content generator, rewriting sitemap locations to the selected website origin. The 1,000-row pages respect PostgREST's row cap. Sitemap failures are retryable XML, including the Nginx outage fallback. The static files in `public` provide valid fixed-page XML for a static-only host; production uses the live renderer.

The deployment snippets are `share-metadata.nginx.conf` and `share-metadata.compose.yml`. Keep each site's website pointer independent, back up ingress before reloading, and verify with wildcard crawler requests and both domains. Run `node --test tests/share-metadata.test.mjs` and `bun test tests/sitemap-serving.test.ts`; API regression coverage is in its separate repository's `tests/sitemap.test.ts`.

Cloudflare must also allow non-browser sitemap fetches. Both website zones have a `http_config_settings` rule named `Tatakai public crawler files`, with ref `tatakai_public_crawler_files`. For GET/HEAD on the website hosts' `/robots.txt`, `/sitemap.xml`, `/sitemap.xsl`, and `/sitemap-*.xml` paths (including canonical trailing-slash redirects), it sets `bic: false` and `security_level: essentially_off`. Browser Integrity Check stays enabled globally; WAF and API/auth protections remain active. Preserve this exception during zone configuration updates. A successful request with a browser-like User-Agent alone does not prove sitemap accessibility: verify a plain non-browser client and Google's fetcher signatures too.
