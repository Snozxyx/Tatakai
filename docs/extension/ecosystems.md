# Source extension ecosystems

Use **Add extension** with a `.kai` file, a public/package URL, a Stremio `manifest.json` URL or `stremio://` link, or a Seanime JSON manifest. Review metadata and configuration before installing. Existing packages need no signing step.

Stremio streams and subtitles use the HTTP/JSON protocol. Resource types and ID prefixes must match the AniList-to-IMDb mapping. Series requests require both upstream season and season-relative episode numbers; Absent mappings trigger a bounded title search in addon catalogs and Cinemeta. Matched metadata supplies movie IDs or advertised episode IDs. Complete, contiguous season metadata can map absolute anime episodes across upstream seasons. Ambiguous titles and incomplete episode sequences return diagnostics; no episode IDs are invented. Stream trials proceed to another matched ID after failures. Addons with catalog, metadata and stream resources expose their own IDs through the existing “+” custom-source pages. These IDs stay separate from AniList mappings. Standalone subtitle addons contribute tracks even when they return no video sources. Desktop configuration opens a contained browser window, captures its `stremio://` result and returns the configured manifest to Tatakai. Browser users can paste the configured manifest URL or `stremio://` link into Add extension. Personalized URLs remain in local storage.

Seanime JavaScript and TypeScript streaming, torrent, and manga providers use the `Provider` methods. TypeScript compiles at installation, and executable bundles cache locally. Common fetch, HTML selection, preferences, encoding and timer helpers bind inside the provider wrapper. Go providers, system/UI plugins and additional unsupported host APIs require Seanime. On desktop, Tatakai supports ChromeDP.newBrowser with navigate, evaluate, sleep, close and executeCDP("Network.getCookies"). JavaScript/TypeScript custom media sources expose anime/manga through the “+” flow and match titles to installed content providers. Missing content matches return explicit diagnostics. Unsupported calls report errors rather than silently succeeding.

Streaming and manga providers automatically match upstream IDs or normalized title aliases, prefer the selected sub/dub variant, and save the mapping per provider and media. Unmatched titles report a provider diagnostic without opening a selection dialog. Saved mappings and preferences can be reset from extension preferences. Manga preserves upstream title and chapter IDs. Enabled state, bundle code and preferences survive restart and updates. Independent providers can fail without removing other sources.

Desktop/mobile use native HTTP and media proxies for headers. Browser requests depend on CORS, and a browser cannot apply arbitrary upstream request headers to its video element. Torrent playback requires a torrent-capable host.

Public imports include source providers only. Listings retain upstream URLs, ecosystem, provider type/language and provenance. Imported compatibility describes the available adapter, not tested functionality. Installation always requires a user's action.

Protocol references: [Stremio](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/protocol.md), [Seanime manifests](https://github.com/5rahim/seanime/blob/main/internal/extension/extension.go).

Source labels use manifest names while routing keeps stable provider IDs. Manga language falls back to manifest `lang`; unknown audio remains unspecified. With Developer Mode enabled in desktop App Settings or Mobile App Settings, source diagnostics show per-provider counts, timing and errors for native and remote anime/manga results, with URLs redacted. See the [complete compatibility audit](../../tatakaiextension/docs/extension-audit.md) for the approved server catalog and prepared local entries. Passing protocol checks does not certify live playback.

Seanime response bodies are buffered once so synchronous and awaited body readers both work. `LoadDoc` supports callable selectors on desktop and mobile. Cached providers receive the current adapter on startup. Desktop runtime changes require restarting Tatakai. HTTP 403 or HTML returned by an API endpoint remains an upstream availability error even when the adapter supports the provider.

The extension page includes a Manga filter for manga providers and custom manga sources. Video settings list every distinct custom/source subtitle, including multiple releases in one language; tracks can be selected before their background VTT conversion finishes. Up to four conversions run concurrently. Custom watch pages retain subtitle tracks from every quality source and offer playback retry. Legacy loopback media wrappers are decoded and registered with the current native media proxy.

Comix uses the desktop ChromeDP compatibility host. When its site requests clearance, a separate Tatakai browser window opens for the user to complete the check; cookies and User-Agent remain scoped to that provider. Browser sessions use isolated, temporary partitions, restrict navigation and cookie reads to the provider website, deny Node access and close on unload or timeout. Native browser setup permits up to three minutes per provider call and excludes browser waiting from cumulative execution time. Mobile and browser-only installations cannot run this ChromeDP provider. Other ChromeDP methods report explicit unsupported-API errors. Comix is covered by an unchanged pinned upstream provider fixture, with simulated site/security-module responses; this does not certify live site availability.

Setup recommendations rank extensions with banners first, then by install count (downloads break ties), and choose the top five from the complete catalog. External-only and unavailable listings are omitted. Developer Mode is off by default, persists on desktop, and updates diagnostics immediately when toggled on desktop or mobile. Development builds also require the explicit setting.
